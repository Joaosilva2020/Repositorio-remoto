# Projeto: Controle de Versão e Colaboração com Git

## 1. Objetivo

Utilizar o Git e o GitHub para controlar as versões dos arquivos, registrar alterações e permitir que os integrantes da equipe trabalhem de forma colaborativa, evitando a perda de versões funcionais e a sobrescrita do trabalho dos colegas.

## 2. Integrantes

- Integrante 1: Ana Silva (nome ficticio)
- Integrante 2: Carlos Oliveira (ficticio)

## 3. Requisitos resumidos

- Instalar e configurar o Git.
- Criar um repositório Git para o projeto.
- Criar um arquivo README.md para documentar o projeto.
- Registrar alterações utilizando commits.
- Utilizar o GitHub para compartilhar o código.
- Criar branches para desenvolver funcionalidades separadamente.
- Utilizar merge para integrar as alterações.
- Resolver conflitos quando dois integrantes modificarem o mesmo arquivo.

## 4. Tecnologias utilizadas

- **Git:** sistema de controle de versão.
- **GitHub:** plataforma para hospedar e compartilhar o repositório.
- **Markdown:** linguagem utilizada para documentar o projeto.
